# QZ-01 - Quiz System
## Overview
The game must contain a Quiz System with Software Engineering Questions in order to promote the Department of Computer Science (DCS) by showing them what they study.
## Requirements
### Questions
The Game must have questions about subjects studiedn in the DCS, which the player has to answer.
#### Punishment
Failing to answer the questions must result in a punishment.
### Quiz UI
A Quiz UI, ressembling an actual computer OS, must be created
#### Folders
Different Quiz Material of the DCS and their subfolders must be represented by folders.
