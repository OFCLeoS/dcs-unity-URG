# File Naming
## Files other than Code
Files other than code are to be named as follows:

**{field}\_{description}\_v{M.m}.{extension}**

Where:
- field
    - Refers to the field the artifact belongs to (ARCH, PM, etc...)
- description
    - Text that describes the specific contents of the file
- M.m (OPTIONAL)
    - Major(M) and minor(m) version numbers. Use only when it makes sense, such as in important files that contains information that concerns the project directly
- extension
    - File type

Examples:
- ARCH_WeaponBallistics_v3.9.uml
- PM_ProgressReport.md
- REQ_UserStories_v1.0.md
