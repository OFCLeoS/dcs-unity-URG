# Branch Naming Practices
Branches are to be named as follows:

**{ticketID}-{branchFeature}**

Where:
- ticketID
    - The specific ticket ID for the feature relating to the branch.
- branchFeature
    - The feature which will be worked on the branch

Examples:
- 39-weapon_handling (notice the use of underlines in the branch feature)
- 93-health_system
- 45-ai
