# Team Member Profile Formatting
If you are a new team member, you should create a file with your information in the [profiles](/PM/profiles/) folder.\
The profile file name should be the same name as your GitHub username.\
A profile file represents a team member and must be formatted as follows:\
**\<NAME LAST_NAME, GITHUB_USERNAME, EMAIL, DISCORD_USERNAME\>**

Example:

File Name: OFCLeoS.md
File Contents: Leandro Sousa, OFCLeoS, leandroptfr123@outlook.com, leos_s
