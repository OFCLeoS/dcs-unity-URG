# QZ-01 - Quiz System
## Overview
The game must contain a Quiz System to enforce learning to the player and to add the education possibilty into the game.
## Requirements
### Questions
The Game will have questions about the DCS, which the player has to answer.
#### Punishment
Failing to answer the questions will result in a punishment.
### HUD
The HUD will display the Quiz System inside the game.
#### Quiz Window
The Quiz Window represents the interface of the questions.
#### Folders
The Folders represent the different Quiz Material of the DCS and their subfolders are more detailed Material.
