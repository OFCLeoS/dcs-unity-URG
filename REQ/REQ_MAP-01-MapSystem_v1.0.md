# MAP-01 - Map System
## Overview
The game must generate a random map for each passing wave.
## Requirements
### Modular Components Support
The map must be able to be generated using modular rooms and components in predefined layouts.
### Floor Theme
A random "Floor Theme" will be chosen for each map. For example, if the Floor Theme is "Lab", then the generated map will contain Lab Assets.
### Room Connection
Room Connection must be done  automatically in order to allow quick layout development.
