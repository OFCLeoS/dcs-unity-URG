# dcs-unity-URG
Repository for the BINFO Semester 4 Software Engineering Project.
# Game Information
DCS (Digital Confinement System) is a Top-Down wave based shooter with an Education Quiz System that teaches the player Computer-Science Subjects.
# How To Play
Unzip the "DCS.zip" folder, located inside the "GAME" folder and run "Digital Confinement System.exe"
