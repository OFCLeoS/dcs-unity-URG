# Digital Confinement System

Digital Confinement System (DCS) is a top-down, wave-based shooter developed as a Software Engineering university project by a team of four.

The game combines arcade-style combat with an integrated Software Engineering quiz system, allowing players to answer questions related to Software Engineering while progressing through the game.

## Project Overview

* **Genre:** Top-down wave-based shooter
* **Engine:** Unity
* **Language:** C#
* **Team Size:** 4
* **Platform:** Windows

## Gameplay
Players fight through waves of enemies while interacting with an in-game educational quiz system covering Software Engineering topics.

## Running the Game

A playable Windows build is provided in the `GAME` directory.

1. Open the `GAME` directory.
2. Extract `DCS.zip`.
3. Run `Digital Confinement System.exe`.

## Opening the Project

The project can be opened through Unity Hub, using the repository root as the project directory.

## Team
