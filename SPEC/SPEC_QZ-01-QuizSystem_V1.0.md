# QZ-01 - Quiz System
## Questions
The Game will have different questions about the 3 different topics of DCS. These Questions will be about certain subtopics of each topic.
### Punishment
Failing to answer the questions will be punished, for example with (TK).
## HUD
The HUD will display the folders of each topic, and a Window for the Quiz System.
### Quiz Window
The Quiz Window shows a question, and also the topic, subtopic, and the specific paragraph which contains the answer to the question. 
The Quiz is a multiple choice quiz of 6 possible choices.
### Folders
We have 3 topic folders, inside each topic folder, inside these are more folders, which are the subtopics of each of these topics. 
Inside these subtopic folders, are the txt/md files with an explanation of these topic/subtopic, with paragraphs to find the correct answer for the question later on, when answering.
